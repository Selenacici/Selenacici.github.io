Talented Host 政策

本次政策更新重点
  1. 调整 J、K、L 三个档位的 Lucky Gift 每周淘汰门槛，以及完成各项薪资任务后可领取的奖励金额。
  2. 新增 Talented Host 申请升级为 Star Host 的资格条件与人工审核流程。

Talented Host 计划为高质量主播提供更多曝光与更好的收入机会，分为 J、K、L 三档。

1. 计划权益

  • 专属个人资料标签
  • 专属直播间标识及流量扶持
  • Talented Host 专属任务薪资
  • 申请晋升 Star Host 的机会

2. 申请与生效

  • 完成至少 30 分钟独立直播。
  • 直播期间收到超过 100 钻石。
  • 计划当前仍有可用名额。

申请视频：不使用特效或重度滤镜；画质清晰；与摄像头距离适当；不少于 30 秒；清楚展示主播才艺。

生效时间 审核通过后，从下一个周一 00:00（UTC+8）开始执行。

3. 档位与每周自动升级模式

Talented Host 的档位按照主播加入计划后的周数每周自动升级，无需主播另外申请：

  1. 第一周：L Talented Host。所有新加入计划的主播从 L 档开始。
  2. 第二周：K Talented Host。主播进入计划后的第二周自动升级为 K 档。
  3. 第三周及以后：J Talented Host。主播进入计划后的第三周自动升级为 J 档，之后继续保持 J 档，直至资格被取消或成功升级为 Star Host。

主播每周需要按照当周所在档位，完成相应的 Lucky Gift 淘汰门槛和薪资任务。

每周淘汰规则

平台每周按照主播当前所在档位检查 Lucky Gift 收礼金额。主播当周未达到对应档位要求，将被淘汰并取消 Talented Host 资格：

  • L 档当周 Lucky Gift 少于 20K 钻石，将被淘汰。
  • K 档当周 Lucky Gift 少于 30K 钻石，将被淘汰。
  • J 档当周 Lucky Gift 少于 40K 钻石，将被淘汰。

被淘汰后，Talented Host 专属权益将被取消，主播薪资恢复为基础 Live 方案；主播后续不可再次申请加入 Talented Host 计划。

4. 薪资任务

实际薪资按任务完成情况计算。每日最多 3 小时直播计入任务，超出部分不计入当天进度。主播需要按照当周所在的 J、K 或 L 档领取对应任务奖励。

5. Talented Host 申请升级为 Star Host

平台不接受普通主播直接申请 Star Host。主播必须先加入 Talented Host 计划，并同时满足以下条件，才有资格提交 Star Host 升级申请：

  1. 当前必须为 J Talented Host。也就是主播已经进入 Talented Host 计划的第三周或以上。
  2. 最近连续两周的平均 Lucky Gift 收礼金额必须大于 $20。计算方式为：最近两周 Lucky Gift 收礼金额之和 ÷ 2，结果必须严格大于 $20。
获得申请资格不代表自动升级

满足以上条件后，主播仅获得提交 Star Host 升级申请的资格。主播需要向官方提交申请，并等待平台进行人工审核。

人工审核内容：平台将综合评估主播整体质量、直播表现、活跃情况、直播内容与互动质量、规则遵守情况及其他相关因素。只有通过人工审核后，主播才能正式升级为 Star Host；未通过审核的主播继续保持原 Talented Host 身份，并按照当前档位规则参与每周考核。
