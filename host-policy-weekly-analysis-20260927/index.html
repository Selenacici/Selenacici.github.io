1. 总体经营判断

政策切换后，整体薪资效率明显改善

  • 主播记录数从 265 降至 212（-20.0%），薪资从 $4,073 降至 $2,877（-29.4%）。
  • 平台利润从 $2,423.47 增至 $4,458.59（+84.0%），利润/薪资由 0.60x 提升至 1.55x。
  • Lucky Gift 增长 9.4%，但直播时长下降 25.7%，单位直播时间的产出显著提高。

Star Host 是本周利润改善的主要来源

  • Star Host 从上周独立表的 64 名收缩至本周 G/H/I 档的 24 名。
  • Star Host 平台利润从 $534.24 增至 $2,303.96（+331.3%），薪资下降 54.6%。
  • G/H/I 三档利润/薪资均超过 1.5x，说明新档位结构已明显改善旧 Star 体系的成本效率。

4. 下周经营重点

  1. 保持 Star 档位收缩效果：Star 人数与薪资显著下降，但礼物和利润上升。继续观察 G/H/I 档位能否在下一周维持至少 1.5x 的利润/薪资。
  2. 改善 Talented K 档：K 档利润/薪资只有 0.92x，应优先检查薪资任务完成质量、Lucky Gift 转化和低利润市场分布。
  3. 关注 Talented 的地区亏损：India、Venezuela、Colombia、Pakistan 和 Ecuador 合计为负利润；Indonesia、Philippines 虽为正利润，但薪资覆盖率较低。
  4. 统一周报字段：后续应保留“薪资等级”作为主播类型的唯一判断字段。本周合并表不再使用 user_tag 区分 Star 与 Talented。

数据口径

  • 9/14–9/20：Talented Host 与 Star Host 使用各自独立工作表，分别统计 201 名与 64 名。
  • 9/21–9/27：使用最终合并工作表，按薪资等级分类。G/H/I 为 Star Host，共 24 名；L/K/J 为 Talented Host，共 188 名。

  • 两类主播本周均采用 Talented Host 薪资方案，因此 Star Host 本周薪资取合并表中的 Talented Host Salary 字段。
