3. 为什么会产生差异

三份名单不是同一个身份字段的不同展示，而是三个独立维护的状态：

数据源实际回答的问题
后端 config_type后端配置表目前把谁配置为 Talented Host。
current_salary_mode当前薪资体系把谁放在 Talented Host 的 J/K/L 档。
user_tag当前用户标签集合中，谁带有 Talented Host 标签。

salary mode 是单值字段的精确匹配；user_tag 是标签数组的“存在元素”匹配。用户可以同时有多个标签，而标签的产生依赖其标签规则和刷新任务。因此它们可能在不同时间写入、刷新，或采用不同准入规则。

共同的 239 人在 J/K/L 薪资等级上完全一致，说明账号关联、导出和等级分组没有系统性错误；差异来自字段值本身。
