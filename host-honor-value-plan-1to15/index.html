02 / METHOD

核算方法与取整原则

新门槛＝当前1:10门槛×10 ÷ 15＝当前门槛的2/3
礼物类型收益倍数计算示例1:15等值荣耀值
Lucky Gift按4倍礼物收益20K钻石×4＝80K收益等值钻石80K÷15＝5.33K
Luxurious Gift按普通礼物1倍收益1M钻石×1＝1M收益等值钻石1M÷15＝66.67K
取整原则精确值出现小数时原则上向上取整，并优先选择便于政策解释和任务排列的整数，避免因为取整而降低原有经济价值。
