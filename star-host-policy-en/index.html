Star Host Policy

Key Updates in This Policy
  1. New Star Host retention and downgrade rules have been added.
  2. Three Star Host levels—A, B and C—have been introduced.
  3. Live-streaming tasks and the reward paid at each level for completing every task have been revised.
  4. A method for assigning each host’s initial level in the first week of the new policy has been added.

Star Hosts are divided into A, B and C levels. Weekly Lucky Gift results determine retention, promotion or downgrade. A host’s current level also determines the available salary tasks and rewards.

1. First Week of the New Policy: Initial Level Assignment

When the new policy takes effect, the platform will use each host’s Lucky Gift income from the week immediately before implementation to assign the host’s initial level for the first week:

Initial Assignment Happens Only Once

This method is used only to assign levels for the first week of the new policy. Starting with the implementation week, the platform reviews each host weekly using the retention and promotion thresholds for the host’s current level.

Promotion Rule

Levels are reviewed once per week. If a host reaches the applicable promotion threshold during the assessment week, the host moves up one level the following week: C to B, or B to A. A is the highest level. A host may be promoted by no more than one level per week.

Downgrade Rule

If a host does not meet the retention threshold for the current level during the assessment week, the host moves down one level the following week: A to B, B to C, or C to J Talented Host. Regardless of how far below the threshold the result is, a host may be downgraded by no more than one level per week.

Examples: an A-level host below $40 moves to B the following week; a B-level host at $40 moves to A; a C-level host at $10 moves to B; and a C-level host with less than 70K Lucky Gift diamonds moves to J Talented Host.

3. New Salary Plan and Task Rewards

Hourly salary tasks are removed after a host becomes a Star Host. A maximum of 4 live-streaming hours per day count toward salary tasks. Weekly live time is counted from 00:00 (UTC+8) on the first day of each week, and all tasks refresh weekly. Hosts receive the task rewards assigned to their current A, B or C level.

4. How a Talented Host Can Apply to Become a Star Host

The platform does not accept direct Star Host applications from regular hosts. A host must first become a Talented Host and meet all of the following requirements before submitting a Star Host promotion application:

  1. The host must currently be a J Talented Host. This means the host has participated in the Talented Host Program for at least three weeks.
  2. The host’s average Lucky Gift income over the most recent two consecutive weeks must be greater than $20. The calculation is: total Lucky Gift income for the most recent two weeks ÷ 2. The result must be strictly greater than $20.
Eligibility Does Not Mean Automatic Promotion

Meeting the conditions only makes the host eligible to apply. The host must submit a Star Host promotion application and wait for a manual review.

Manual review: the platform evaluates overall host quality, live-streaming performance, activity, content and interaction quality, compliance with platform rules, and other relevant factors. A host becomes a Star Host only after passing the manual review. If the application is not approved, the host remains a Talented Host and continues the weekly assessment for the current level.

5. Application, Live-Streaming and Compliance Requirements

  • Participate in at least one Livehouse event or complete a 20-minute solo live audition.
  • Participate in specified live events as required by the platform.
  • Use a qualified cover, avatar and nickname; maintain a clean and appropriate appearance and proper camera distance.
  • Use suitable live-streaming support equipment and adequate fill lighting; use appropriate background music; actively interact with room users.

6. Violations, Warnings and Cancellation

Fraud, cheating or violation of platform rules immediately terminates the fixed-salary policy and may lead to additional penalties. Star Hosts with negative performance may receive warnings. Three warnings within one month may result in cancellation of Star Host status. The platform may review and adjust eligibility based on performance and compliance.
