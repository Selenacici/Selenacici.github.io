HONOR VALUE TASK REDESIGN

Talented Host 与 Star Host 荣耀值任务更新方案

将礼物类任务从“只统计指定礼物钻石收入”调整为“普通礼物与幸运礼物统一折算荣耀值”，在保留现有薪资上限的前提下，降低完成门槛、统一统计口径，并建立更清晰的任务阶梯。

方案设计 · 待确认 本页不是已生效政策

页面用于内部评估更新前后的变化。门槛经过业务确认和试运行验证后，才能替换正式政策。

01 / OVERVIEW

方案概览

核心变化是统计口径，而不是直接提高最低礼物收入。任务奖励继续使用美元表示。

统计范围
两类礼物

普通礼物与幸运礼物产生的荣耀值均计入任务进度。

主播门槛
保持低难度

基础门槛按照现行幸运礼物要求等值换算，不额外抬高。

薪资奖励
美元不变

奖励仍以 $ 发放，Talented 与 Star 最高周薪保持不变。

实施方式
先试运行

建议观察2至4周，再根据完成率和盈利数据调整高阶门槛。

荣耀值换算规则

礼物类型每100钻石获得荣耀值10,000钻石（$1）对应荣耀值
普通礼物1100
幸运礼物202,000
15,000钻石幸运礼物 = 3,000荣耀值 ＋ 50,000钻石普通礼物 = 500荣耀值 ＝ 合计3,500荣耀值
统一计算原则更新后，普通礼物和幸运礼物都可以贡献任务进度；每周荣耀值重新统计，不累计到下一周。礼物类型不同，因此相同钻石金额产生的荣耀值并不相同。

04 / BUSINESS CONTROL

盈利与难度控制

门槛是否“可盈利”不能只用主播最低门槛与最高周薪作一对一比较，需要结合真实完成率和礼物结构判断。

为什么不继续抬高基础门槛

  • 最高周薪要求完成全部任务，并非每名主播都会获得。
  • 淘汰门槛是保留主播资格的最低标准，不是最高奖励的盈利平衡点。
  • 过度提高基础门槛，会抵消本次降低主播和公会参与难度的目标。
  • 更适合通过高阶任务和实际完成率控制高额奖励成本。

当前尚未验证的业务变量

  • 普通礼物与幸运礼物在各档位的真实收入占比；
  • 充值折扣、支付成本及主播分成后的平台净收入；
  • 各任务的实际完成率与主播平均薪资；
  • 160K和220K高阶任务的完成分布；
  • 淘汰率变化对主播与公会留存的影响。
方案判断边界当前门槛设计是基于现行政策难度进行的可执行调整，但不能在缺少真实收入、分成和完成率数据时声称已经证明整体盈利。
05 / PILOT

建议试运行与确认步骤

先改变统计口径，保留奖励金额，再用2至4周数据验证是否需要微调。

1

确认方案门槛

业务确认Talented Host三档任务，以及Star Host的160K、220K高阶门槛。

2

进行2至4周试运行

只调整礼物任务统计口径，保留直播任务、奖励金额和最高周薪。

3

按周复盘

观察荣耀值分布、任务完成率、平均薪资、淘汰率和留存变化。

4

确认正式版本

若高阶任务完成率过高，优先微调高阶门槛，不先提高新主播淘汰门槛。

试运行核心指标

指标用途
各档位荣耀值中位数判断门槛是否符合真实表现
普通／幸运礼物占比判断新口径的实际难度
各任务完成率识别过易或过难任务
平均礼物收入与任务薪资评估整体成本与收入
主播淘汰率与留存率评估筛选和激励效果
最终建议以4K／6K／8K作为Talented Host淘汰门槛，以14K／20K／80K作为Star Host关键档位门槛；先用160K／220K测试Star Host最后两档任务。完成试运行后，再依据真实数据形成正式政策。
