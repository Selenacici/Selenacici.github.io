Star Host 政策

本次政策更新重点
  1. 新增 Star Host 的保级与降级规则。
  2. 新增 A、B、C 三个 Star Host 档位。
  3. 调整直播任务内容，以及各档位完成每项任务后可获得的奖励。

Star Host 分为 A、B、C 三个档位。主播每周根据 Lucky Gift 收礼结果进行保级、升级或降级，当前档位同时决定其可以参与的薪资任务及对应奖励。

升级规则

平台每周进行一次档位考核。主播在考核周达到当前档位对应的升级门槛，即可在下一周升级一个档位：C 升至 B，B 升至 A。A 为最高档位，不再继续升级。主播每周最多升级一级。

降级规则

主播在考核周未达到当前档位的保级门槛，将在下一周下降一个档位：A 降至 B，B 降至 C，C 降至 Talented Host J 档。无论当周数据低于门槛多少，每周最多只降一级。

档位判定示例：A 档主播当周 Lucky Gift 低于 $40，下一周降至 B；B 档主播达到 $40，下一周升至 A；C 档主播达到 $10，下一周升至 B；C 档主播 Lucky Gift 收礼低于 70K 钻石，下一周降至 Talented Host J 档。

4. Talented Host 如何申请升级为 Star Host

平台不接受普通主播直接申请 Star Host。主播必须先成为 Talented Host，并同时满足以下条件，才有资格提交 Star Host 升级申请：

  1. 当前必须为 J Talented Host。即主播已经进入 Talented Host 计划的第三周或以上。
  2. 最近连续两周的平均 Lucky Gift 收礼金额必须大于 $20。计算方式为：最近两周 Lucky Gift 收礼金额之和 ÷ 2，结果必须严格大于 $20。
获得资格不代表自动升级

满足条件后，主播仅获得提交申请的资格，仍需向官方提交 Star Host 升级申请并等待人工审核。

人工审核内容：平台将综合评估主播整体质量、直播表现、活跃情况、直播内容与互动质量、规则遵守情况及其他相关因素。只有通过人工审核后，主播才能成为 Star Host。未通过审核的主播继续保持 Talented Host 身份，并参加对应档位的每周考核。

5. 申请、直播与合规要求

  • 至少参加一次 Livehouse 活动，或完成一次 20 分钟个人直播试播/审核。
  • 按照平台要求参加指定直播活动。
  • 使用合格的封面、头像和昵称；形象整洁得体；与摄像头保持适当距离。
  • 使用合适的直播支撑设备并保持充足补光；播放合适的背景音乐；主动与房间内用户互动。

6. 违规、警告与资格取消

作弊、欺诈或违反平台规则将立即终止固定薪资政策资格，并可能追加处罚。表现消极的 Star Host 可能收到警告；一个月内累计 3 次警告，平台可取消其 Star Host 资格。平台有权根据主播表现及规则遵守情况审核并调整资格。
