一、管理层结论

核心判断：Star Host 规模稳定（58→59），但连续两周可比的 57 名主播，直播时长下降 4.0%，Lucky Gift 下降 13.7%；达到 $20 Lucky Gift 任务门槛的主播连续两周均为 8 人。
  • 平台利润由正转负：平台利润从 $612.87 转为 $-62.76，游戏利润也从 $457.66 降至 $-3.94；Lucky Gift、时长、送礼用户同步走弱。
  • 任务完成呈明显断层：第二周 56/59 人达到 10h，47 人达到 20h，但仅 21 人达到 24h；Lucky Gift 达到 $2 的只有 25 人，达到 $20 的仅 8 人（13.6%），达到 $100 的为 0 人。
  • 现行薪资缺少持续约束：第二周薪资总额 $2,005.00，较上周 -0.2%；但有 34 人（57.6%）未达到最低 Lucky Gift $2 任务门槛，仍可凭时长取得部分固定薪资。无淘汰机制下，低礼物/低利润状态缺少退出或纠偏闭环。
  • 建议新考核机制双轨化：设置“周度基础活跃线 + 连续低效处理线”。以有效直播、Lucky Gift、平台利润/薪资效率共同评估，而非只看单一时长；设置预警、整改和退出/降级机制，同时保留对优质主播的激励上限。

八、新考核机制建议

  1. 保留入门活跃线：建议每周有效直播时长不低于 10h，避免完全不活跃；并保持每日最多计入 4h，防止单日堆时长。
  2. 引入质量线：以 Lucky Gift、有效送礼用户和平台利润共同判断，避免仅靠时长领取薪资。建议设定至少一个礼物/互动达标条件。
  3. 建立连续低效闭环：单周未达标进入预警；连续 2 周触发整改；连续 3 周仍未达标则降级/退出 Star Host。违规处理继续按现有政策单独执行。
  4. 薪资从“全额任务叠加”转向“基础 + 质量加速”：保留低档时长基础奖励，但将更高档奖励与 Lucky Gift、利润效率绑定，降低“高时长、低产出”的薪资投入。
  5. 设置过渡期和豁免：新机制至少提前一个结算周期公示；对新升级主播、经批准的特殊活动主播设短期过渡，避免误伤优质新星。

九、数据口径与局限

  • 8/31–9/06 源表包含 118 行、59 个唯一账户 ID，存在 59 行重复记录；本报告已按账户 ID 去重，避免人数和金额重复计算。
  • 数据表没有主播加入 Star Host 的日期、当前预警次数、活动参与记录或违规结果，因此无法验证政策中的审核、活动与“三次警告”条款。
  • “主播收到 star host 活动礼物数量”在源数据中为带千分位的数值，未纳入薪资任务达标计算；应在新机制上线前确认该字段的业务定义及是否纳入质量考核。
  • Lucky Gift 的钻石与美元折算沿用 Talented Host 政策数据口径（20K≈$2）进行任务映射，正式考核应直接使用结算钻石值。
